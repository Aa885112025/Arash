# Arash – Deep Search

A lightweight web app featuring a **user profile page** for the Deep Search platform.

## Features

- **Profile sidebar** – avatar, display name, bio, and at-a-glance stats (searches, saved results, collections)
- **Search History tab** – filterable list of past searches with the ability to remove individual items
- **Saved Results tab** – card grid of bookmarked search results with topic tags
- **Settings tab** – editable account information, dark mode toggle, notification preferences, and history opt-out
- **Edit Profile modal** – quick in-place name and bio update that syncs across the page
- **Toast notifications** – non-blocking success feedback after saving changes
- **Responsive layout** – single-column on mobile, two-column on wider screens
- **Dark mode** – automatically follows the OS preference; can be overridden in Settings

## Usage

Open `index.html` directly in any modern browser – no build step required.

```
open index.html
```
